# iTree

Geoinformation system for managing green space data, enabling automation of records for recreation zones, green plantings, and landscaping elements. Includes a mobile app for field work and citizen engagement.

## Functions

- Online map  
- Detailed information about objects  
- User personal account  
- Database  
- Inventory management  
- Data analysis for individual green zones  
- Decentralized data access  
- Support for static planting location data  
- Public registry  
- Object accounting cards  
- Recreation zone information  
- Display of subordinate objects  
- Social media authorization  
- Automated plant name identification  

## Mobile App

iTree includes a mobile application for smartphones and tablets that extends the platform beyond the web interface.

✅ Field inventory — add objects, photos, and attributes during on-site visits  
✅ Real-time data updates directly from the field  
✅ QR and barcode scanning for quick access to object cards  
✅ Mobile services for residents to report issues and provide feedback on tree condition  

Inspectors and municipal services can work on location without duplicating data in paper logs and spreadsheets.

## Use Cases

- Municipal green space management and urban forestry
- Field inventory and monitoring of trees, shrubs, and landscaping elements via mobile app
- Recreation zone planning, maintenance, and public information
- Public registries of city plantings and green infrastructure
- Environmental departments and landscaping services
- Decentralized access to green space data across organizations
